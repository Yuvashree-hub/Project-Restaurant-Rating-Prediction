# Project-Restaurant-Rating-Prediction
# Restaurant Rating Prediction Using Machine Learning

## Project Overview

This project uses Machine Learning to predict restaurant ratings based on restaurant characteristics.

The project uses the Zomato Bangalore Restaurants dataset and applies data preprocessing, exploratory data analysis, feature engineering, and Random Forest Regression to predict restaurant ratings.

The project also provides visual insights into restaurant ratings, votes, cost, locations, and predicted restaurant performance.

---

## Objective

The main objective of this project is to:

- Predict restaurant ratings using Machine Learning
- Analyze factors associated with restaurant ratings
- Compare actual and predicted ratings
- Identify highly rated restaurants
- Visualize restaurant-related trends and patterns

##  Dataset

The project uses the **Zomato Bangalore Restaurants Dataset**.

The dataset contains information such as:

- Restaurant Name
- Online Ordering
- Table Booking
- Restaurant Rating
- Number of Votes
- Location
- Restaurant Type
- Cuisines
- Approximate Cost for Two People

### Dataset Source
